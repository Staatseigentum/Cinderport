# Cinderport 0.3.0 — A bigger home for every world

Cinderport now has room to grow with more games and tools. This release expands the library, gives you more control over updates, and makes the launcher easier to personalize.

## New in 0.3.0

- Download Center with a queue, transfer progress, speed, remaining time, cancel, and retry.
- App detail pages with version information, gallery images, download size, release notes, and reinstall controls.
- Search, filters, sorting, favorites, and quick access to recently launched apps.
- Update and launch history, plus a News page fed by official GitHub releases.
- Three pixel-art themes inspired by Cinderport, Embercrown, and Kollaps; compact view and reduced-motion setting.
- Optional system tray, desktop notifications, and a Do Not Disturb mode for streaming.
- Individual automatic-update switches, optional launch arguments, manual installation detection, reinstall, cache cleanup, and free-space checks.
- Settings export/import, a copyable diagnostic report, and Stable/Beta update channels for Cinderport.
- Automatic checks for installed apps and Cinderport every 30 minutes.
- A flexible "Coming soon" area for future announced apps.

App downloads still come from official GitHub releases and are checked against their published SHA-256 digests. The Windows installer is currently unsigned.
